## Что делает сервер

1. Создаёт TCP-сокет.
2. Привязывает его к порту 8080.
3. Переходит в режим listen.
4. В цикле принимает клиентов через accept.
5. Для каждого клиента создаёт структуру client.
6. Запускает отдельный поток через pthread_create.
7. Поток worker принимает данные и отправляет их обратно клиенту.
8. Поток отсоединяется через pthread_detach, поэтому серверу не нужно отдельно ждать завершения каждого клиента.
