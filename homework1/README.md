# ДЗ: компьютерные сети и TCP-сервер

Репозиторий содержит материалы для двух заданий:

1. **Схема сети и таблица уровней** — пример расчёта IPv4-сети, схема клиент–сервер, соответствие OSI и TCP/IP и ответы на вопросы.
2. **TCP-сервер на три соединения** — программа на C для Linux/POSIX, которая принимает ровно три подключения, отправляет каждому клиенту его IP-адрес и TCP-порт, после чего завершает работу.

network-homework-repo/

## Важно про параметры своей сети

В `docs/report.md` приведён **учебный пример**: `192.168.10.42/24`, шлюз `192.168.10.1`, DNS `1.1.1.1`. Это не измерения вашего компьютера. Перед сдачей замените эти значения на четыре параметра, которые показывает ваша ОС: IPv4, маска, шлюз по умолчанию и DNS-сервер. Не публикуйте в открытом репозитории публичный IP, если не хотите раскрывать его.

## Сборка и запуск TCP-сервера (Linux)

Нужен компилятор GCC или Clang.

```bash
gcc -Wall -Wextra -Wpedantic -std=c11 -O2 src/server.c -o server
./server
```

Сервер слушает TCP-порт `9000` на всех IPv4-интерфейсах. Он обслуживает три подключения **последовательно**. Для каждого подключения отправляет строку вида `hello, 127.0.0.1:54321`, где порт — фактический исходный порт клиента. После третьего клиента закрывает слушающий сокет и завершает процесс.

### Проверка

Откройте три отдельных терминала (или выполните команды по очереди, пока сервер работает):

```bash
nc 127.0.0.1 9000
```

Каждый клиент должен получить приветствие. После третьего подключения сервер завершится. Четвёртый запуск `nc` после завершения сервера не сможет подключиться, потому что порт больше не слушается.

Если `nc` не установлен, установите пакет `netcat` средствами своего дистрибутива. Для проверки на другой машине вместо `127.0.0.1` укажите IP компьютера-сервера; убедитесь, что локальная сеть и правила firewall разрешают TCP-порт 9000.

## Как создать Git-репозиторий

В терминале перейдите в распакованную папку проекта и выполните:

```bash
git init
git add .
git commit -m "Добавлены материалы двух заданий"
```

Чтобы создать репозиторий на GitHub:

1. Войдите на GitHub и нажмите **New repository**.
2. Назовите репозиторий, например `network-homework`.
3. Для учебной работы можно выбрать **Private**, если преподавателю не нужна публичная ссылка.
4. Не добавляйте на GitHub README или `.gitignore` повторно — они уже есть в этой папке.
5. Скопируйте адрес репозитория, затем выполните команды GitHub, например:

```bash
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/network-homework.git
git push -u origin main
```

Замените `ВАШ_ЛОГИН` на свой логин. При запросе авторизации используйте способ входа, предложенный GitHub (обычно браузер или Personal Access Token, а не пароль аккаунта).

После изменения файлов отправляйте обновления так:

```bash
git add .
git commit -m "Обновлён отчёт"
git push
```
